# Project Rubric

## Clear Identification of the Base Project and Its Original Scope (3pts)

- [ ] Student identifies the original project they are extending.
- [ ] Student provides a short description of the original system's goal and capabilities.
- [ ] Description is accurate and sets clear context for extensions.

## Substantial New AI Feature Added (3pts)

- [ ] Student adds at least one substantial AI feature such as RAG, a multi-step agent or planning workflow, specialized behavior (mini fine-tune or structured prompting), or a reliability harness (evaluation loop, guardrails, self-checking).
- [ ] Feature is integrated into the working system (not an isolated demo).
- [ ] Feature is functional and produces meaningful changes in system behavior.

## System Architecture Diagram (3pts)

- [ ] Diagram shows major components (UI/CLI, retrieval, agent, evaluator, database, etc.).
- [ ] Diagram clearly illustrates data flow (input → processing steps → output).
- [ ] Diagram matches actual project implementation (not theoretical).

## Functional End-to-End System Demonstration (3pts)

- [ ] Student provides a working script or UI that demonstrates full system workflow.
- [ ] System runs end-to-end using the new AI feature.
- [ ] System responds consistently to at least 2-3 example inputs.

## Reliability, Evaluation, or Guardrail Component (3pts)

- [ ] System includes a reliability mechanism such as input validation, output guardrails, self-critique or multi-model agreement, or an evaluation script that tests sample inputs.
- [ ] Mechanism is functional and meaningfully improves reliability.
- [ ] Student provides examples demonstrating how the guardrail/evaluator behaves.

## Documentation: README and Setup Instructions (3pts)

- [ ] README clearly explains project goals and new features.
- [ ] README contains step-by-step instructions to install, run, and test the system.
- [ ] README includes sample input/output illustrating system behavior.

## Reflection on AI Collaboration and System Design (3pts)

- [ ] Student explains how they used AI during development (prompting, debugging, design).
- [ ] Student identifies at least one helpful and one flawed AI suggestion.
- [ ] Student reflects on system limitations and future improvements.
